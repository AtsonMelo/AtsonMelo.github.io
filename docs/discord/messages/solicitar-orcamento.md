**Como pedir um orçamento · How to request a quote**

**PT-BR**
1. Abra **Tópicos** neste canal (ícone # no topo) → **Criar tópico** → marque como **Privado**. Só você e o dono do servidor veem.
2. Cole o briefing abaixo (o site gera um pronto em https://atsonmelo.github.io, na seção Contato).
3. Combinamos escopo, entregas, prazo e valor **por escrito** antes de começar.
⚠️ Não poste tokens, chaves de licença, senhas ou IPs. Se for preciso compartilhar acesso, combinamos um meio seguro.

**EN**
1. Open **Threads** in this channel (# icon at the top) → **Create Thread** → set it **Private**. Only you and the server owner can see it.
2. Paste the brief below (the site builds one for you at https://atsonmelo.github.io, Contact section).
3. Scope, deliverables, timeline and price are agreed **in writing** before work starts.
⚠️ Never post tokens, license keys, passwords or IPs. If access must be shared, we agree on a safe way.

**Briefing / Brief**
```
Project type:
Framework (Qbox / QBCore / ESX / standalone / unsure):
Desired feature:
Description (what it should do; what is broken or slow today; deadline):
How to reach you:
```
