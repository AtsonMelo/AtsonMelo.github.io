**Como pedir um orçamento · How to request a quote**

O pedido fica num **tópico privado**. Outro cliente não vê o seu. A equipe vê porque o dono do servidor enxerga os tópicos privados deste canal. Não há envio automático: o site apenas copia o texto.

**PT-BR**
1. Abra **Tópicos** neste canal (ícone no topo) e crie um tópico **privado**. Não dá para escrever no canal em si: isso é de propósito, para o briefing não ficar público.
2. Se o seu Discord não oferecer "tópico privado", escreva só isto em <#suporte>: `quero um orçamento`. Não descreva o projeto lá. A equipe abre o tópico e adiciona você.
3. Cole o briefing. O site publicado (https://atsonmelo.github.io/, seção Contato) monta o texto e avisa que ele **não foi enviado**.
4. Escopo, entregas, prazo e valor ficam **por escrito** antes de começar.
5. Não envie token, chave de licença, senha, IP ou `server.cfg`. Se precisar de acesso, combinamos um meio fora do chat público.

**EN**
1. Open **Threads** in this channel (icon at the top) and create a **private** thread. You cannot type in the channel itself; that is intentional, so the brief stays off the public channel.
2. If your Discord client has no "private thread" option, post only this in <#suporte>: `I need a quote`. Do not describe the project there. The team opens the thread and adds you.
3. Paste the brief. The published site (https://atsonmelo.github.io/, Contact) builds the text and states that it was **not sent**.
4. Scope, deliverables, timeline, and price are agreed **in writing** before work starts.
5. Do not send tokens, license keys, passwords, IPs, or `server.cfg`. If access is required, we agree on a way that is not a public chat.

**Briefing / Brief**
```
Project type:
Framework (Qbox / QBCore / ESX / standalone / unsure):
Desired feature:
Description (what it should do; what is broken or slow today; deadline):
How to reach you:
```
