    DevLab Phone

    Implemented

    • HUD button, cursor mode, navigation stack and layered ESC handling.
    • NUI ↔ Lua handshake with reconnect, and an RPC pipeline with idempotency and rate limiting.
    • Apps: home widgets, garage (vehicle-call state machine), messages, DevBank and PIX flow.
    • Banking and messages are simulations with demo data; no real value is moved.
    • User text is rendered as plain text; HTML in messages stays literal (covered by a test).

    Verification

    • 617 Lua assertions, 5 Node unit tests, 112 headless Chromium end-to-end checks.
    • Run on 2026-10-19, 0 failures. All with a simulated FiveM bridge.

    Not done yet

    • In-game verification on GTA V Enhanced (NUI focus, ESC vs. pause menu).
    • Persistence, Qbox adapter and real player-to-player messaging.

    DevLab Character

    Implemented

    • Appearance presets (face, hair, beard, clothing slots) applied through the game’s ped component and overlay natives.
    • Every piece is validated against what the current game build actually has; missing ones are skipped and logged instead of guessed.
    • In-game calibration tools: step through pieces, keep the one you like; saved per player on the server and reused on the next apply.
    • Optional re-apply on join and respawn.

    Verification

    • 389 offline Lua assertions, 0 failures (2026-10-19).

    Not done yet

    • Nothing has been verified visually in GTA V Enhanced yet, so no screenshots are shown. The card uses a placeholder on purpose.

    DevLab Core

    Implemented

    • Input validation, rate limiting and structured JSON logging shared by the other resources.
    • Booted on a real local FXServer: resource starts, logs its events and answers a console status command.

    Verification

    • 29 offline assertions, 0 failures (2026-10-19).
    • Lesson learned: offline tests with a simulated require hid a real load error. Only the runtime boot exposed it, so it was fixed and covered by new tests.

    Not done yet

    • In-game test with a connected client (ping/pong, rate limit, player ACE).
